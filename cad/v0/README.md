# v0: the original Biropette (frozen)

The 2014 Biropette by Tom Baden ("PIPETTE v16" and "PIPETTE RACK v1"), tidied
in 2025, with the STL and 3MF exports printed from it in `prints/`.

- Pipette: <https://www.thingiverse.com/thing:255519>
- Rack: <https://www.thingiverse.com/thing:257254>
- Guide: `docs/v0/`

It is kept for attribution and comparison and is not edited. `just check`
still renders it so that it stays usable. v1 replaces the mechanism; see
`docs/design.md` §2.
